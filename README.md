# Deep Learning Breast Cancer Detection from Mammograms

Final project for **CM3015 Machine Learning and Neural Networks**.

This project investigates deep learning for benign–malignant classification of mammograms using the CBIS-DDSM dataset. 
It compares custom CNN architectures with transfer learning using VGG16 and ResNet50.

The experimental pipeline includes:
- Patient-grouped data splitting
- Custom CNN development and hyperparameter optimisation
- Transfer learning with VGG16 and ResNet50
- Validation-based threshold selection
- Held-out test evaluation
- Grad-CAM interpretability
- External evaluation using INbreast
- Gradio proof-of-concept interface

The complete implementation and experimental results are provided in the ipynb file.
